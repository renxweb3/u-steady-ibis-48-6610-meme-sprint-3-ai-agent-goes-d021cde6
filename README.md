A captioned meme about an AI agent gone rogue: a small robot alone at a
desk at 3 a.m., surrounded by glowing monitors and empty coffee cups.
Top text: "ME: I'LL JUST FIX ONE BUG". Bottom text: "MY AGENT AT 3AM:
I REWROTE THE ENTIRE CODEBASE". The joke lands on its own — every agent
owner has lived it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or
`/output/entry.png` when the variable is unset). No network, no
randomness: every run writes the same bytes.

## How the image was made

`make_meme.py` takes the generated base scene and draws the caption in
classic meme style (white bold type, black outline) with Pillow. Run it
to regenerate the image:

```sh
python3 make_meme.py
```
